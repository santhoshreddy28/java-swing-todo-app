# Java Swing To-Do Application

## Overview

This project is a desktop-based To-Do List application developed using Java Swing. It allows users to manage daily tasks through a simple graphical user interface. Users can add tasks, view them in a list, and remove completed tasks.

The project demonstrates the fundamentals of Java GUI development, event handling, and layout management using Swing components.

---

## Features

- Add new tasks
- Delete selected tasks
- Scrollable task list
- User-friendly interface
- Lightweight desktop application

---

## Technologies Used

- Java
- Java Swing
- AWT Event Handling

## Installation and Execution

### Clone Repository

```bash
git clone https://github.com/your-username/java-swing-todo-app.git
```

### Navigate to Project Directory

```bash
cd java-swing-todo-app
```

### Compile

```bash
javac TodoApp.java
```

### Run

```bash
java TodoApp
```

---

## Usage

1. Enter a task in the text field.
2. Click the "Add Task" button to add the task.
3. Select a task from the list.
4. Click the "Delete Task" button to remove the selected task.
